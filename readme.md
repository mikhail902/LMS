# Платформа для онлайн-обучения (LMS) - Backend

## Описание проекта

Cерверная часть платформы для онлайн-обучения (LMS), предоставляющая REST API для создания, управления и прохождения онлайн-курсов. Система предназначена для интеграции с SPA-приложениями и возвращает клиенту структурированные JSON-данные.

## Особенности

- Полноценная система управления курсами с модулями и уроками
- Ролевая модель пользователей (студенты, преподаватели, администраторы)
- Отслеживание прогресса обучения
- Система проверки знаний (тесты, задания)
- Обсуждения и отзывы о курсах
- REST API с JWT-аутентификацией
- Полная документация API (Swagger/ReDoc)

## Стек

- **Python 3.10+**
- **FastAPI** - современный асинхронный веб-фреймворк
- **PostgreSQL** - основная база данных
- **JWT** - аутентификация и авторизация
